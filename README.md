## Personal Website Source

In the project directory, you can run:

### `npm run dev .`
### `npm run build`

Builds the static site, removes the previous generated files from `production/`,
and copies in the contents of `build/client/`. Git metadata, `CNAME`, `404.html`,
`.nojekyll`, `LICENSE`, and `README.md` are preserved. Commit and push the generated
files from that checkout when ready to publish.
